PAKHI BIRTHDAY WEBSITE

Includes:
- Happy Birthday Sweetheart ❤️‍🩹 opening section
- Dreamy animated pastel birthday background with twinkling decorations
- Soft generated instrumental melody with Play/Pause button (tap to start; browsers block autoplay)
- Separate photo gallery with 3 photos and tap-to-enlarge
- Three separate envelope buttons, each opening its own birthday letter

GitHub Pages upload:
1. Extract this ZIP.
2. Upload index.html and the entire photos folder to the root of your GitHub repository.
3. Keep the photos folder name and photo filenames unchanged.
4. Ensure Settings > Pages uses branch main and folder /(root).
5. Wait a few minutes for the website to update.
